ANIMOA 3.11.4 — CORRECTIF URGENT DEMANDE D’AVIS

1. Dans Supabase > SQL Editor, exécuter une seule fois : supabase/sql/09_correctif_boucle_avis.sql.
2. Remplacer les fichiers du site par ceux de cette version.
3. Envoyer les changements sur GitHub puis faire Push origin.
4. Attendre le nouveau déploiement Vercel et actualiser Animoa avec Ctrl + F5.
5. Tester avec un compte utilisateur :
   - « Envoyer mon avis » ferme définitivement la demande automatique ;
   - « Plus tard » ferme immédiatement la fenêtre et laisse accéder à l’application ;
   - une erreur réseau ne doit jamais rouvrir la fenêtre en boucle ;
   - le bouton permanent « Donner mon avis » reste disponible dans Paramètres.
