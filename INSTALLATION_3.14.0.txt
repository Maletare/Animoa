ANIMOA 3.14.0 — FACEBOOK : PUBLICATION + PROGRAMMATION
======================================================

Cette version conserve le générateur visuel 3.13.1 validé et ajoute :
- publication réelle sur la Page Facebook Animoa ;
- programmation en heure de Paris ;
- modification / reprogrammation / annulation avant envoi ;
- statut Programmée / Envoi en cours / Publiée / Erreur ;
- traitement automatique côté Supabase même si l’ordinateur est éteint ;
- contrôle de la connexion Facebook ;
- alertes J-14 / J-7 / J-3 avant l’échéance de l’accès aux données ;
- rappel e-mail à J-7 via Brevo.

IMPORTANT AVANT LE TEST FACEBOOK
================================

Ne mettez aucun token dans ce dossier, dans supabase-config.js ou dans .env.local.
Les secrets Facebook restent uniquement dans Supabase Edge Function Secrets.

Secrets attendus côté Supabase :
- FACEBOOK_PAGE_ACCESS_TOKEN
- FACEBOOK_PAGE_ID
- FACEBOOK_DATA_ACCESS_EXPIRES_AT
- ANIMOA_CRON_SECRET (déjà existant dans le projet)

Le rappel e-mail réutilise les secrets Brevo déjà configurés dans Animoa.

ORDRE DE MISE EN PLACE SUPABASE
===============================

1) Si ce n’est pas déjà fait, exécuter :
   supabase/sql/11_publications_facebook_admin.sql

2) Déployer / redéployer :
   supabase/functions/animoa-facebook-publications
   Nom : animoa-facebook-publications

3) Déployer :
   supabase/functions/animoa-facebook-dispatch
   Nom : animoa-facebook-dispatch

   Cette fonction est appelée par le Cron sans JWT utilisateur et se protège elle-même
   avec ANIMOA_CRON_SECRET. Le fichier supabase/config.toml contient sa configuration.

4) Exécuter :
   supabase/sql/12_publications_facebook_programmation.sql

   Ce script ajoute la programmation et crée deux Crons :
   - animoa-facebook-due-every-minute : vérifie chaque minute et appelle l’Edge Function uniquement si un envoi est dû ;
   - animoa-facebook-health-daily : contrôle quotidien pour le rappel Facebook J-7.

5) Ouvrir Animoa avec le compte administrateur puis :
   Menu > Administration > Publications Facebook

6) Vérifier le bandeau :
   « Facebook connecté ✓ · Animoa »

7) Faire d’abord un test avec « Publier maintenant ».
   Une fois ce test validé, faire un test de programmation quelques minutes dans le futur.

SÉCURITÉ
========
- Aucun .env.local n’est inclus dans le ZIP.
- Aucun token Facebook n’est inclus dans le ZIP.
- Le navigateur ne reçoit jamais le token de Page Facebook.
- Le répartiteur Cron exige ANIMOA_CRON_SECRET.
- Une publication déjà prise par le répartiteur est verrouillée pendant son envoi.
